## 🚀 About the App

**GossipApp** is a full-featured Android chat app with real-time messaging, group chats, friend management, notes, and push notifications — all powered by Firebase.

---

## ✨ Features

| Feature | Description |
|--------|-------------|
| 💬 Private Chat | One-on-one real-time messaging |
| 👥 Group Chat | Create groups and chat together |
| 🤝 Friends | Add and manage friends |
| 📝 Notes | Personal notes section inside the app |
| 🖼️ Image Sharing | View and share images in chat |
| 📄 PDF Viewer | Share and view PDF files |
| 😄 Reactions | React to messages |
| 🔔 Push Notifications | FCM-powered real-time alerts |
| 🔐 Authentication | Login / Sign up via Firebase Auth |
| 🎭 Splash Screen | Animated typewriter splash screen |
| 👤 User Profiles | Profile management with avatar |

## 🏗️ Setup & Installation

1. **Clone the repo**
```bash
   git clone https://github.com/umang4zq/GossipApp.git
```
2. **Open in Android Studio**
3. **Connect Firebase**
   - Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
   - Download `google-services.json` and place it in `app/`
   - Enable Firestore, Auth, Storage, and FCM
4. **Build & Run** on emulator or device
